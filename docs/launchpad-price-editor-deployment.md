# 启航第八批：内建批量调价表

本批复用现有产品查询、原价检查及 `apply_product_prices`，没有新数据库结构。已部署前七批即可直接提交／推送／Vercel Ready，不需要 SQL 或新环境变量。

## 功能与边界

- 管理员「目录设置与导入」新增折叠「批量调价表（管理员）」。销售员即使有产品管理权限也不能使用此表，后台提交仍强制管理员身份。
- 搜索／分类读取当前公司 30 项产品，不读取／签发不需要的照片。单项加入或加入当前页，跨页不丢选择，重复编号不重复加入，最多 10,000 项。
- 待调价清单每页 30 行；编号、名称、原价只读，输入新价。CSV 未匹配编号可在匹配前修正；不能通过表变更已有产品编号。
- 选取／输入／导入／检查都不写价格，需「检查调价表」再「确认提交」。空价、负价、三位小数拒绝，零元允许；同价不更新，不存在不新增，重复的全部行跳过。
- 选取时记录产品 ID、原价与 revision。检查不自动更新已选原价；变化会提示冲突，必须明确「重读表内原价」保留新价、再次检查。删除后同编号的新产品也不会被自动替代，需移除旧行并重新选。
- CSV 可导入到表后编辑新价、移除重复行／修正未匹配编号，再检查；文件 5MB／10,000 行、分隔符和字段对应沿用原解析。
- 导出待调价表为 SKU、新价与程序编号编码标记，保护前导零和公式样式的 SKU。可以导回新表或旧 CSV 调价；Excel 不要修改编号编码列。超过 5MB 提示分批，不静默截断。
- 提交开始即锁定整批输入。失败／暂停用同一 UUID、原 payload 重试，复用旧后台幂等、原价／revision 检查和操作记录。确认的行不再次改价，不会覆盖之后别人的修改。
- 每批 100 行可暂停。需要编辑时明确开始新任务，丢弃本页进度但不回滚已改价格；旧原价快照仍需显式重读，不悄悄覆盖新价输入。
- 检查／结果可下载，使用原报告字段；表内行号对应导出 CSV 的数据行（row_number＋2），不假称来自原上传文件的实际物理行。历史报价、其他产品字段和原只新增 CSV 不改。
- 草案及任务进度仅在当前页面内存，离开／刷新提醒；刷新后已提交价格与后台记录保留，不承诺跨设备续传草案。
- 与编号、CSV 和分类操作互斥忙碌状态，复杂操作收在管理员页，不增加顾客下单／付款或库存功能。

## 线上验收（测试公司）

1. 搜索／分类选两项，填新价检查；确认前价格未变。
2. 确认后目录新价、其他字段和历史报价不变，结果可下载。
3. 开新任务后原价变化应提示；明确重读不清空新价。
4. 导出并导回，前导零编号及零元正确；重复／不存在／非法价可修正或移除，未确认不写入。
5. 员工无表入口；本地实际 PostgreSQL 测试继续验证提交权限。
