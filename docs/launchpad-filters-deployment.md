# 启航第七批：30 条分页与业务筛选

顺序：一次运行 `202610070001_launchpad_filters.sql` → 只读 `launchpad_filters.sql` PASS → 本地提交／GitHub Desktop 推送 → Vercel 新提交 Ready → 测试公司验收。无需新增环境变量。

- 公司产品目录、外部顾客目录、分享管理产品选择均每页 30 项，报价／回收站每页 30 张。链接列表、公司后台、客户通讯录仍保留原分页；CSV 预览行数不变。
- 管理员报价可以按创建员工及报价顾客筛选；员工不能使用员工筛选，顾客候选只来自自己的报价。
- 员工选项包含管理员、停用或移除成员，历史单仍可按原创建者查找。仅管理员调用现有受保护的公司成员 API。
- 顾客按报价保存的名称匹配（不是必须有通讯录 ID），支持手填／旧报价；同名顾客的报价合并筛选，名字变化不回写历史。候选支持搜索及 30 项分页，不一次渲染全部顾客。
- 报价默认马来西亚日期的最近 30 天；按报价单 `quote_date` 查询，单日／区间均含首尾最多 30 天（结束－开始最多 29）。可查询更早历史，不删旧记录；搜索、员工、顾客和状态都与已应用日期组合。
- 日期表单需点击查询，显示当前已应用区间。31 天、倒序、缺失日期由界面与新后台查询接口双重拒绝。旧接口保留兼容，不扩大任何读取权限。
- 管理员客户通讯录有建立者筛选。其他员工无筛选控件；伪造他人建立者参数也被拒绝；管理员不能修改别人的客户。
- 改筛选重置到第一页；分页不清空产品目录里的报价草稿。不涉及库存、收费、完整翻译或内建 CSV 编辑器。

测试：至少 61 项产品／61 张报价（本地模拟数据）；员工／顾客组合查询，2000 年历史日期及 30／31 日边界；客户建立者权限；公开目录无价格、私有分类不泄漏；旧生成／编辑／分享流程回归。线上只用测试公司，不为试验批量修改真实资料。
