# JomSales 视觉与外壳规范（Design System）V1

来源：Figma 截图 `CAT_产品目录`、`Log In / Sign Up`（用户设计）。本文只把截图里已有的风格固化成可实现的规则；截图没覆盖的页面按这里的规则推导，不另起风格。
代号沿用 `docs/JomSales-UIUX-代号总表-v1.md`。实现者：Codex。审阅：Claude。

> 实现前先读 `AGENTS.md`：本项目的 Next.js 16 与旧版本有差异，写布局/路由前读 `node_modules/next/dist/docs/`（先 `npm ci`）。

## 1. 设计令牌（写进 `app/globals.css` 的 `:root`，取代现有 `--blue/--dark`）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--navy` | `#252b53` | 主按钮、标题、选中态、导航激活、药丸标签 |
| `--navy-ink` | `#161a32` | 弹层背后的遮罩底色（遮罩 `rgba(22,26,50,.55)`） |
| `--green` | `#0b8200` | 「分享」类动作（分享卡片、分享报价、复制/发送链接） |
| `--chip` | `#e0e2ed` | 标签 chip 底色（文字 `--navy`） |
| `--ph` | `#d9d9d9` | 无图占位 |
| `--link` | `#2f9bff` | 低频文字链接（原「编辑」蓝字；改为 ⋯ 菜单后仅用于次要链接） |
| `--bg` | `#ffffff` | 页面背景（Figma 为白底，不再用 `#f4f6f8`） |
| `--surface` | `#f6f7fb` | 分组底、输入禁用底 |
| `--text` | `#161a32` | 正文 |
| `--muted` | `#6b7280` | 说明、占位 |
| `--border` | `#252b53`（输入框 1px）/ `#e5e7eb`（分隔线） | |
| `--danger` | `#dc2626` | 删除、撤销、错误 |
| `--ok` | `#0b8200` | 成功状态 |
| `--warn` | `#b45309` | Pending 等待态 |

字体：Inter（拉丁/数字）+ 系统中文（PingFang SC / Microsoft YaHei）。用 `next/font` 加载 Inter，不外链。
圆角：输入框 12px；按钮 = 全圆角药丸（`999px`）；卡片 12px；弹层 20px；产品图 8px。
间距：4 的倍数；页面左右 16px；区块间 16–24px。
触控：可点击元素最小 44×44px。字号：页面标题 22/700，弹层标题 24/700，正文 14，辅助 12。
数字价格用 `font-variant-numeric: tabular-nums`。
禁止：纯灰色置灰当作“无权限”（无权限必须隐藏，见总表 §0）。

## 2. 基础组件（对应总表 G.*）

- **G.PRIMARY_BUTTON**：navy 底、白字、药丸、高 48；整行宽用于表单提交。
- **G.SECONDARY_BUTTON**：白底、navy 1px 描边、navy 字、药丸。
- **G.SHARE_BUTTON**（新增）：green 底、白字、药丸；只用于「分享」动作。
- **G.DANGER_BUTTON**：白底 danger 描边/字；确认弹窗内的危险确认用 danger 实心。
- **输入框**：白底、navy 1px 描边、12px 圆角、高 48、占位 `--muted`；必填标签在名称后加 `*`；错误时描边变 danger，错误文字在输入框正下方（G.INLINE_ERROR）。
- **G.BACK**：左上角 40px navy 实心圆 + 白色返回箭头（见 Auth 截图）。下面一条 1px `#e5e7eb` 分隔线，标题在线下。
- **G.CLOSE**：弹层右上角 navy 实心圆 + 白色 ✕。
- **G.MORE**：「⋯」图标按钮，44×44 点击区；菜单为小浮层，项高 44。
- **G.CONFIRM**：居中弹层，标题一行 + 一句说明 + 两个按钮（取消在左=次要，确认在右=主要；危险时确认为 danger 实心）。点遮罩 = 取消。
- **G.TOAST**：底部导航上方 12px，2.5 秒消失，不挡按钮；错误不用 toast，用 G.INLINE_ERROR。
- **Chip**：`--chip` 底、navy 字、12px、圆角 6。
- **状态药丸**：Pending=warn 描边、Success=navy 实心、Paid=green 实心。
- **分页**（G.PAGE_*）：`←` `页码` `→`，← → 为 navy 药丸小按钮，不可用时 `--chip` 底（见 Figma）。
- **空状态 ST.EMPTY / ST.NO_RESULTS**：居中一句话 + 一个明确动作（如「新增产品」），不放长说明。
- **加载 ST.LOADING**：骨架块（卡片位置灰块），不用整页「正在读取…」文字。

## 3. 外壳（App Shell）

### 3.1 成员日常外壳 `G.NAVBAR`
- 固定底部悬浮胶囊导航（白底、阴影、圆角 24、左右各 16px 边距，安全区留白）。
- 五项固定顺序：**产品 · 客户 · 报价单 · 分享 · 我的**（图标在上、文字在下，12px；选中项 = `--chip` 圆角底 + navy 图标）。
- 「报价单」图标右上角红点/navy 圆徽章 = 当前报价行数（行数 0 不显示；≥100 显示 `99+`）。
- 对应：产品→`/cloud`(CAT)、客户→`/customers`(CUS)、报价单→当前报价 QTE、分享→`/catalog-share`(SHR)、我的→ME。
- **不显示导航的页面**：登录/注册/验证/重置/邀请/等待（AUTH.*）、`/c/<token>`（PUB）、平台后台（PLT.*）、弹层打开时（被遮罩盖住）、QTE 内键盘弹出时。
- 页面底部内容必须留出导航高度（≥ 96px），避免遮挡分页和提交按钮。

### 3.2 顶部标题区 `G.TOPBAR`
- **CAT 专用头部**（见 Figma）：头像圆（用户首字母，navy 描边）+ 「管理员 - RYAN」/「销售员 - XXX」（角色 - 姓名）+ 下一行邮箱（12px muted）；其下一行：公司药丸（白底 navy 描边，居中公司名，点开 G.COMPANY_PICKER；仅一家公司时不可点）+ 右侧「N 项产品」navy 实心药丸（CAT.TOTAL）。
- **其他页面**：左 G.BACK（有上一层时）或无；标题 22/700；右侧最多一个次要动作（图标）。
- 公司名过长：单行省略，点开选择器看全名。

### 3.3 弹层规范
- 底部居中弹层（手机宽度时宽度 = 屏宽 − 32），遮罩 navy-ink；标题 + 一句副标题（12px muted）+ 右上 G.CLOSE。
- 表单型弹层（PDE）：内容区可滚动，底部按钮固定，永远可见。
- 打开弹层时锁定背景滚动；ESC/遮罩点击关闭 = 走 D.DISCARD（有改动时）。

### 3.4 响应式
- 以 390px 手机宽度为设计基准；平板/桌面：内容容器最大 560px 居中（不做桌面多栏）；导航胶囊同宽居中。
- 产品列表手机 2 列；≥ 560px 仍 2 列（卡片更大），不做 3 列。

### 3.5 图标
- 统一线性图标 1.75px 描边；用一套内联 SVG（不引外部图标 CDN），放 `app/icons.js`。
- 需要：产品(袋)、客户(电话)、报价单(文档)、分享(纸飞机)、我的(人)、加号圆、搜索、清除✕、筛选、返回、关闭、更多⋯、刷新、下载、勾、眼睛/眼睛斜杠、箭头→、箭头←。

## 4. 文案与语气
- 简体中文；按钮 2–6 字，动词开头（「保存产品」「加入报价」）。
- 不出现技术词（RPC、token、RLS）；错误文案说清「发生了什么 + 下一步」。
- 价格统一 `RM 20.00`（RM 与金额间一个空格；两位小数；千分位逗号）。单位前加 ` / `（`RM20.00 / 件`，按 Figma）。
- 日期 `2026-10-07`；时间 24 小时制。

## 5. 验收
1. `:root` 令牌与本表一致；全站不再出现旧蓝 `#2563eb`、旧灰底 `#f4f6f8`。
2. 390px 宽无横向滚动；所有可点元素 ≥ 44px。
3. 导航在 §3.1 所列页面显示/隐藏正确；报价徽章随行数变化。
4. 浏览器回归 `scripts/test-workspace-browser.cjs` 通过并补充导航断言；`npm test`、`npm run build` 通过。
