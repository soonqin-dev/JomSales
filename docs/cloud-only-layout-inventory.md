# 旧版 SalesGo 页面清单（已停止使用）

当前设计请使用 [JomSales 最新页面与按钮清单](jomsales-layout-inventory.md)。下方仅保留历史参考，创建公司、账号、安全和报价等描述已经过时。

这是代码功能结构，不是视觉设计。新报价流程需先部署 migration 005 和回收站清理任务；
本地测试不代表线上已启用。产品详情和产品表单是弹层；报价编辑器位于 `/cloud`
内，不是独立 `/quotation` 路由。

## 全局流程

打开 SalesGo → 未登录进入账号页 → 登录 → 未加入公司则创建／接受邀请 →
公司产品目录。员工只用受邀邮箱注册／登录，无需自行创建公司。

所有产品、报价、客户资料和品牌以公司云端为准，不提供访客本地模式。
报价草稿仅在页面内存，生成／分享时自动保存；离开未保存资料时提醒。
登录态可记住，不必每次打开输入密码。共用设备提供明确退出入口。

## 1. 账号 `/account`

- 登录／注册管理员账号；来自邀请时显示注册员工账号。
- 邮箱、密码；登录／注册并验证邮箱；重新发送验证邮件。
- 已登录：账号邮箱、所属公司、角色与产品权限、进入公司、退出此设备登录。
- 无公司：公司名称、创建公司；员工等待管理员邀请。
- 来自邀请：返回邀请并确认加入。
- 管理员所属公司卡片：员工与邀请入口。

状态：读取中、网络失败、邮箱验证提醒、登录失败、无公司。
设计登录和注册可用同页标签或独立视觉页面，但现有路由相同。
暂未开发忘记密码，不将它误画成已可用功能。

## 2. 公司产品目录 `/cloud`

- 顶部：公司名称、当前权限；多公司时公司选择。
- 导航：公司账号、已保存报价；管理员额外看到员工与邀请、公司品牌。
- 刷新云端产品、重新读取报价与品牌。
- 报价购物车数量、查看／生成报价。
- 当前报价标识：新报价／正在编辑：编号；正常进入和刷新默认新报价。
- 新建报价单：清空当前清单，留在目录；未保存修改会先提醒，已保存报价不变。
- 搜索编号／名称／标签；清除搜索。
- 产品卡片：照片、名称、编号、标签、价格；查看详情。
- 新增、编辑、删除：仅管理员或获产品管理权限的销售员看得见。
- 普通销售员仍可查看、搜索、分享、创建自己的报价。

状态：加载、空目录、搜索无结果、图片失败、权限撤回、云端读取失败。

### 产品新增／编辑弹层

编号、名称、标签、价格、图片上传、图片预览、移除图片、取消／关闭、保存。
保留手机图片格式兼容、转换中、保存中、失败保留表单和价格验证提示。

### 产品详情弹层

公司 Logo／名称、产品图片／名称／编号／标签／价格。
关闭；分享卡片到 WhatsApp／重新生成卡片；下载产品卡片；加入报价清单；查看报价。
加入产品只更新当前草稿，显示「生成／分享时自动保存」，不提前创建云端报价。

## 3. 报价编辑（`/cloud` 内视图）

- 返回目录、新建报价、已保存报价；不提供手动保存按钮。
- 当前报价标识：新报价／正在编辑：编号。
- 产品行：名称／编号、数量、单价、行金额、移除。
- 客户名称、客户电话。
- 报价编号只读、日期、备注、折扣、小计／总额。
- 公司名称／联系方式／Logo 快照，只读；管理员可跳到公司品牌管理。
- 生成报价 PDF：自动保存、生成并下载，然后回到目录清空当前清单。
- 准备分享 PDF（自动保存）→ 分享 PDF：成功后回到目录清空；取消／失败保留。
- 目录保留刚生成 PDF 的下载／分享入口，便于浏览器不支持直接分享时手动发送。

状态：空报价、无效数量／价格／折扣、未保存、保存中、保存失败、另一设备修改冲突、
PDF 生成中／失败、浏览器不支持分享。生成 PDF 前先确认云端保存。
已保存报价在新建后仍保留；旧品牌快照不随当前品牌更新而改变。

## 4. 已保存报价 `/quotations`

- 公司名称、自己的／公司全部报价的权限说明。
- 返回公司目录、新建报价、刷新报价列表、回收站。
- 搜索编号／客户／员工邮箱；按 Pending／Success 筛选。
- 每条显示编号、客户、日期、所属员工邮箱、状态；选择报价立即回到目录继续加产品。
- 标记 Pending（待确认）／Success（客户确认成交，不代表收款）。
- 删除报价：确认后移入回收站；恢复报价：保留原编号、内容、状态和所属员工。
- 销售员只看自己的，管理员可看本公司的全部报价。

回收站：15天内可恢复，到期后不可恢复，后台每小时永久清理一次。
员工只管理自己的回收站，管理员可见全公司及所属员工。
状态：加载、空列表、错误、版本冲突、恢复已过期。目前没有订单或报表按钮。

## 5. 公司品牌 `/brand`（管理员）

公司名称、联系方式、Logo 上传／预览／移除；保存公司品牌、重新读取、返回目录。
展示未保存、转换中、保存中、保存成功、权限／版本冲突。
只影响当前产品卡片和后续新报价，不改历史报价。

## 6. 员工与邀请 `/team`（管理员）

- 公司选择、返回账号／目录、刷新。
- 输入员工邮箱、生成邀请链接、复制链接。当前不自动发送邮件。
- 成员列表：邮箱、管理员／销售员、访问状态。
- 销售员：一个「产品管理（新增、编辑、删除）」开关；停用／恢复权限。
- 管理员受保护，没有降级／停用按钮。
- 邀请记录：邮箱、待接受／已接受／已撤销／已过期、到期时间、撤销待接受邀请。

## 7. 加入公司 `/join`

- 未登录：使用受邀邮箱注册／登录、返回账号。
- 登录后：公司名称、受邀邮箱、销售员角色、到期时间、接受邀请／确认公司访问权限。
- 成功后：进入公司目录。重新检查邀请；换账号入口。
- 状态：加载、邮箱错误、未验证、过期、撤销、已停用、无效链接。

## 8. 邮箱验证 `/auth/callback`

确认中 → 成功自动去邀请或公司入口；失败显示返回账号／重新发送邮件的提示。

## 设计优先级

先设计登录／注册、公司目录、产品详情、产品表单和报价编辑这条主流程。
再设计报价列表、公司品牌和员工管理；邀请／验证补齐状态页即可。
建议先用手机宽度设计，保留清楚的错误、权限与保存状态，不只提供正常状态布局。
