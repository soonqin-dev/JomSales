# JomSales 邮件模板（中文）

日期：2026-10-07。状态：**草稿，等负责人审阅**。

用途：粘贴到 Supabase 后台 Authentication → Email Templates。这是后台配置，不是代码，也不在应用界面里显示。

## 使用说明

- 每个模板有「主题」和「正文」两部分，分别粘贴到 Supabase 对应的两个输入框。
- 正文里的 `{{ .ConfirmationURL }}`、`{{ .Email }}`、`{{ .NewEmail }}` 是 Supabase 的变量，**原样保留，不要改动**。
- 只需要这三个模板。员工邀请是管理员手动复制链接发送的，不经过 Supabase 邮件，所以没有邀请模板。魔术链接和重新验证（Reauthentication）模板目前没有使用。
- 正文使用最简单的 HTML，不放图片和多余样式，避免被邮箱当成垃圾邮件。
- 链接有效期取决于 Supabase 后台设置，文案里不写具体时间，避免和实际不符。
- 粘贴后，用自己的另一个邮箱各测试一次：注册验证、忘记密码、更改邮箱。检查链接能打开、没有出现乱码或变量原文。

## 1. 确认注册（Confirm signup）

主题：

```
请验证你的 JomSales 邮箱
```

正文：

```html
<h2>验证你的邮箱</h2>
<p>你好，感谢注册 JomSales。</p>
<p>请点击下面的链接，验证这个邮箱：</p>
<p><a href="{{ .ConfirmationURL }}">验证邮箱</a></p>
<p>请在注册时使用的同一个手机浏览器中打开链接。如果链接打不开，可以直接回到 JomSales，用邮箱和密码登录。</p>
<p>验证完成后，请等待公司管理员发给你邀请链接。打开邀请链接，就可以加入公司。</p>
<p>如果这不是你本人的操作，请忽略这封邮件。</p>
```

## 2. 重置密码（Reset password）

主题：

```
重置你的 JomSales 密码
```

正文：

```html
<h2>重置密码</h2>
<p>我们收到了重置 JomSales 密码的申请。</p>
<p>请点击下面的链接，设置新密码：</p>
<p><a href="{{ .ConfirmationURL }}">设置新密码</a></p>
<p>请在申请重置时使用的同一个手机浏览器中打开链接。链接过期后，请回到登录页面重新申请。</p>
<p>设置新密码后，你在其他设备上的登录会被退出，需要用新密码重新登录。</p>
<p>如果不是你本人申请，请忽略这封邮件，你的密码不会改变。</p>
```

## 3. 更改邮箱（Change email address）

说明：开启了 Secure Email Change 时，Supabase 会把这封邮件同时发给**旧邮箱和新邮箱**，两边都要点击确认，更改才会生效。所以正文同时写出新旧两个地址。

主题：

```
确认更改你的 JomSales 登录邮箱
```

正文：

```html
<h2>确认更改登录邮箱</h2>
<p>你申请把 JomSales 的登录邮箱从 {{ .Email }} 更改为 {{ .NewEmail }}。</p>
<p>请点击下面的链接确认：</p>
<p><a href="{{ .ConfirmationURL }}">确认更改邮箱</a></p>
<p>旧邮箱和新邮箱各会收到一封邮件，两封都确认后，更改才会生效。更改后，你的公司、角色和报价记录都不会变。</p>
<p>如果不是你本人申请，请忽略这封邮件，并尽快修改密码。</p>
```

## 审阅时请确认

1. 称呼用"你好"，不带姓名，因为 Supabase 模板默认拿不到显示姓名。
2. 语气偏简短直接，适合手机阅读。
3. 注册邮件里的"请等待公司管理员发给你邀请链接"这一句，是否符合你对员工入职流程的想法。
